# LT-1

##What the program does
the program calculates how many box can fit in a given box, it is also given how many books can fit inside a box the program also calculates the remaining notebook

##How to run it
open the file in any python compiler
run it

##What the user types in,  and what comes out
the user types in how many notebooks
then the user types in the capacity of the box
the program calculates how many notebooks can fit in one box and how many are left
after that the program displays how many notebooks can fit in a box and how many notebooks left
